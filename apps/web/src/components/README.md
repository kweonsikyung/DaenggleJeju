# components

Provider·Portal·Context 등 UI가 아닌 래퍼 패턴 컴포넌트 모음입니다.  

## 디렉터리 구조

- `Toast/` — 전역 알림 컴포넌트
- `ModalProvider/` — 모달 상태/포털 Provider
- `FormProvider/` — react-hook-form 컨텍스트 Provider
- `Portal/` — GlobalPortal, Layer 등 포털 관련

## import

```ts
import Toast from "@/components/Toast";
import { FormProvider } from "@/components/FormProvider";
```
